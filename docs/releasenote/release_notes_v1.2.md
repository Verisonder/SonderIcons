# SonderIcons 1.2

## Read first: one reinstall

1.0 and 1.1 were signed with a temporary key. From 1.2 on, every release is signed with
SonderIcons' own key, so updates install over each other.

To move to 1.2 without losing your setup:

1. In your current version, there is no backup yet, so note anything you want to keep.
2. Uninstall SonderIcons, install 1.2.
3. From now on, use Settings, Backup, Save backup before any reinstall.

## New

- **Themed copies of pinned shortcuts.** Extras lists the shortcuts apps have pinned to
  your home screen. Pin a themed copy that opens exactly what the original opens (Brave
  web apps stay standalone), then remove the original.
- **Unknown icons: As they are.** No filter, so themed shortcut copies keep their icon.
- **Backup and restore.** Every choice and picture in one file, from Settings. Works on a
  new phone or after reinstalling.
